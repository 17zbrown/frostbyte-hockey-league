Run game nightPicks and lineups lock 30 minutes before puck drop — set them before then

Every game night runs through Team HQ: set your server picks, dress each game before it locks, hand your players the private code at T-30, and rebuild any lag-out after the horn.

Schedule desk

Pick your servers, then watch it lock

One card per night. Home names two servers; away sets a veto and a preferred. Picks are private to each club.

3

Set your server picks — there is no Save button

Away, you set Veto — won’t play and Preferred; home, 1st choice · home and 2nd choice. Each choice saves the moment you change it — “Veto & preferred saved” or “1st & 2nd choices saved”. A bad pair resets and warns: “1st and 2nd choices must differ.”

Lineup builder

Dress each game before it locks

Each game’s lineup locks 30 minutes before its own puck drop — not the night’s first. Get them all in before then.

5

Dress every game

In the night plan, point each night at a saved line under Dresses, then press Dress 1 game — or Dress the week (2) to do every night at once. Dressing runs the same checks as the builder: weekly limits, suspensions, and the lock. Tune a single game in the per-game builder.

6

When a game locks

The per-game builder then reads Status: Locked · locked 8:30 PM ET (Rule 5.3), every filled slot shows OVR nn · locked, and the only button left is Emergency call-up.

7

Only an emergency call-up gets in

For a genuine no-show, confirm “Start an emergency call-up?” → Enable call-up, swap the player, then press Submit emergency call-up. Every player you change after lock costs your club one in-game penalty. Rule 5.3

Matchup center

The code drops at T-30

Open a game’s Match card for the private code, both confirmed sheets, and the lobby settings.

8

Grab the private lobby code at T-30

Before release the box reads Code releases at T-30 with the time. From T-30 it shows Private game code · live and the six digits — “Released 8:30 PM ET · visible to rostered players and staff only.” Never post a code anywhere public. Rule 4.2

9

Set the lobby to the league standard

The Lobby settings card is the checklist: EASHL 6v6 · Club Private, 3 × 4:00, Continuous 4:00 periods — no shootout, Grudge Match Off. For Sides, match the site — the club listed Home selects Home, Away selects Away — or the box score lands on the wrong side. Rule 4.1

Game stats

Rebuild a lag-out from its sittings

Finals import from EA within minutes of the horn. When a game lags out, only part of it lands — open that game from Game stats and rebuild it.

Game stats · “Fix a lag-out” on the game that lagged (a game still waiting shows “Enter it manually”; a forfeit you won, “Enter the played game”)
10

Open the fixture and select every sitting

Under Sittings EA recorded, pick the first half and everything played after the lag-out — they are summed into one final, with overtime taken from the deciding sitting. Sittings under ten minutes get a warn chip; anything already on this game or tied elsewhere is marked. If the archive is empty, press Check EA for this game’s sessions.

11

Rebuild — it replaces the box score

Press Combine the selected sittings into this game and confirm “Rebuild this game from 2 sittings?” The old box score is replaced; standings, player totals, and profiles update immediately, and league staff are notified. Rule 4.3

For the players

You are told only when you are in

A rostered player sees the same slate — but the card only ever makes a positive claim, never a negative one.

12

Check your dashboard, then grab your code

When your name is in the confirmed lineup, the slate says so: “You’re in the confirmed lineup at Left Wing. Your private game code goes live at 8:30 PM ET — open the matchup to grab it.” A healthy scratch, a missing line, and a failed load all show the same generic caption — so if you are unsure, ask your GM.

Watch outTwo different locks. Server picks freeze for the whole night 30 minutes before the night’s first puck drop; each game’s lineup locks 30 minutes before its own drop. A 9:40 game’s picks are frozen at 8:30, but its lineup stays open until 9:10. And never share a code outside the two rosters — that is a conduct violation (Rule 4.2).
Good to knowThe Game stats desk opens only your own club’s games — the server re-checks your seat, so a link to a game that is not yours reads “That fixture isn’t one of yours.” By convention the winning club enters the stats after a forfeit win or a win that followed a disconnect. Forfeits themselves (Rule 3.2, 1–0, no stats) are ruled by statistics staff, not from your desk.
